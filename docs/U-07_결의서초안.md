# U-07 정산 서류 자동 작성 (지출결의서 초안)

> 작성: 노은비 · 2026-11-03
> 코드: `backend/app/precheck/voucher.py` (`draft_voucher`, `suggest_account`)
> 테스트: `backend/app/precheck/tests/test_voucher.py` (13개)

U-04 와 **같은 요청(청구 내역)**을 받아 담당자에게 올릴 **지출결의서 초안**을 만듭니다.
건명·적요, 계정과목 제안, 첨부서류 목록, 제출 기한을 채우고, U-04 사전검증 결과를 같이 붙입니다.
**결재는 하지 않습니다.** 초안일 뿐이고 결재는 위임전결규정 시행세칙에 따른 결재권자가 합니다 (회계규정 시행세칙 제11조).

## 흐름

```
U-05 출장비 계산 ──▶ verify_request ──▶ U-04 사전검증 ──▶ U-07 결의서 초안 ──▶ 제출 ──▶ M-01
U-06 영수증 초안 ──▶ items ────────────┘
```

## API (제안)

`POST /api/voucher-draft` — 요청은 `/api/verify` 와 같고, 아래만 추가로 받을 수 있습니다.

| 필드 | 설명 |
| --- | --- |
| `requester` | `{ "name": "홍길동", "department": "해운정책팀" }` |
| `title` | 건명을 직접 정할 때 (없으면 자동 생성) |
| `tax_invoice` | 세금계산서가 있으면 `true` → 첨부서류에 추가 |
| `verify_result` | 이미 받은 `/api/verify` 응답 (없으면 내부에서 다시 검증) |

## 철도·버스 증빙 곤란 시 사유서 템플릿 (`reason_forms`)

> 2026-11-08 추가 · 근거: 실무자 의견 반영(5주차 코칭) — 증빙이 어려우면 대중교통 인가요금을 기준으로 하고,
> 정확한 사유를 적어 부서장 승인을 받은 결재문서로 증빙을 대신할 수 있음

철도·버스 항목에 `"receipt": false` 가 있으면 결의서 초안 응답에 `reason_forms` 가 붙고, 첨부서류에
"증빙 대체 결재문서(사유서 · 부서장 승인)"가 추가됩니다. 택시·항공 등은 해당하지 않습니다.

| 항목 필드 (선택) | 설명 |
| --- | --- |
| `route` | 이용 구간 (예: 서울역 → 부산역) |
| `authorized_fare` | 같은 구간 대중교통 인가요금 |
| `no_receipt_reason` | 증빙이 어려운 사유 |
| `substitute_approved` | 부서장 승인 결재문서를 받았으면 `true` |

```jsonc
"reason_forms": [{
  "document": "교통비 증빙 대체 사유서",
  "for_item": "철도운임",
  "status": "작성 필요",                      // 승인받았으면 "부서장 승인 완료"
  "fields": [
    { "key": "route", "label": "이용 구간", "value": "서울역 → 부산역", "placeholder": "예: 서울역 → 부산역 (편도)", "required": true },
    { "key": "reason", "label": "증빙이 어려운 사유", "value": "",
      "placeholder": "예: 역 현장에서 현금으로 발권했고 승차권을 분실해 결제 내역을 조회할 수 없음", "required": true }
    // 건명 · 작성자 · 출장 기간 · 이용 수단 · 청구 금액 · 인가요금 기준 · 부서장 승인
  ],
  "guide": ["청구 금액은 같은 구간 대중교통 인가요금을 넘을 수 없습니다.", "…"],
  "basis": "실무자 의견 반영(철도·버스 증빙 곤란 시 결재문서 대체)"
}]
```

- 화면은 `value` 가 비어 있으면 `placeholder` 를 **흐린 글씨 예시**로 보여주고, 직원이 사유에 맞게 고쳐 쓰게 합니다.
- U-04 검증: 결재문서 없이 영수증만 없으면 "보완 필요"(사유서 작성 안내), 결재문서가 있고 인가요금을 넘으면
  "보완 필요"(`T-TRANS-SUBSTITUTE-FARE`), 인가요금을 모르면 "담당자 확인 필요"(`T-TRANS-SUBSTITUTE-CHECK`).

## 계정과목 제안 규칙

KOBC 실제 계정과목 코드표는 공개되어 있지 않습니다. 그래서 **규정 원문에 이름이 나오는 예산과목**은 "규정 확인", 나머지는 "가정"으로 표시합니다.

| 항목 | 제안 과목 | 수준 | 근거 |
| --- | --- | --- | --- |
| 출장 일비·식비·숙박비·교통비 | 여비교통비 (국내여비) | 규정 확인 | 예산세칙 제22조②, 여비규정 제2조 |
| 업무협의·간담회 | 업무추진비 | 규정 확인 | 업무추진비 지침 제2조① |
| 경조금·화환 | 업무추진비 (경조사비) | 규정 확인 | 업무추진비 지침 제2조① |
| 회의·다과·회식, 출장 외 식사 | 조직관리비 (부서운영비) | 규정 확인 | 업무추진비 지침 제2조② |
| 문구·소모품 / 도서·인쇄 / 통신·우편 / 교육·세미나 / 수수료 / 차량 정비 | 소모품비 / 도서인쇄비 / 통신비 / 교육훈련비 / 지급수수료 / 차량유지비 | **가정** | 일반 공공기관 비용 과목 |
| 그 외 | 담당자 확인 | - | 회계규정 시행세칙 제6조③ (회계계정은 회계책임자와 사전 확인) |

## 가정한 것

- 계정과목 중 "가정" 표시된 과목, 그리고 세목 이름(국내여비(일비) 등)은 KOBC 내부 코드표와 다를 수 있습니다.
- 결의서 서식(칸 구성)은 공개된 원문에 별지 서식이 없어, 회계규정 시행세칙 제7조(건명·산출내역)와 제8조(붙임서류)에 나오는 항목으로 구성했습니다.
