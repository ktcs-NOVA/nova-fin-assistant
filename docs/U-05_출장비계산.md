# U-05 출장비 자동 계산

> 작성: 노은비 · 2026-11-03
> 코드: `backend/app/precheck/travel_calc.py` (`calc_travel`) · 기준값: `backend/app/precheck/rules.py`
> 테스트: `backend/app/precheck/tests/test_travel_calc.py` (13개)

출장 정보를 넣으면 **여비규정 별표 1** 기준으로 받을 수 있는 금액을 항목별로 계산하고, 계산식과 적용 조항을 같이 보여줍니다.
결과의 `verify_request` 를 그대로 U-04 `/api/verify` 에 보내면 **계산 → 사전검증**이 한 번에 이어집니다.

## API (제안)

`POST /api/travel-calc`

### 요청

```jsonc
{
  "trip_type": "국내출장",               // 또는 "근무지 내 출장"
  "grade": "직원 3급 이하",
  "trip": {
    "start_date": "2026-10-20",
    "end_date": "2026-10-21",
    "region": "부산",                    // 서울 / 광역시 / 기타 또는 도시명
    "vehicle": "대중교통",               // 대중교통 / 업무용차량 / 렌트차량 / 자가용
    "purpose": "",                       // "교육"이면 일비 2일 한도
    "breakfast_nights": 1,               // 조식 포함 숙박 박수
    "meals_provided": 0,                 // 주최 측 무료 제공 식사 수
    "lodging_provided": false,           // 주최 측 숙박 무료 제공
    "hours": null, "round_trip_km": null // 근무지 내 출장만
  },
  "fares": [                             // 선택: 이미 알고 있는 운임 (실비)
    { "type": "철도", "amount": 59800, "seat_class": "일반" }
  ],
  "private_car": {                       // 선택: 자가용일 때
    "distance_km": 400,                  // 운행거리: 사무실 → 출장지, 네이버 길찾기 km
    "fuel": "휘발유",                     // 휘발유 / 경유 / LPG / 하이브리드 / 전기
    "price_per_liter": 1700,             // 출장일 유류단가 (전기는 price_per_kwh)
    // "km_per_liter" / "km_per_kwh" 를 넣으면 유종별 기본 연비 대신 그 값을 씀
    "tolls": 20000, "public_fare": 70000 // 같은 구간 철도·버스 운임 (한도)
  }
}
```

### 응답

```jsonc
{
  "grade": "직원 3급 이하", "region": "광역시", "days": 2, "nights": 1,
  "lines": [
    { "field": "일비", "amount": 60000, "type": "정액",
      "formula": "30,000원 × 2일", "basis": "여비규정 제14조 제1항, 별표 1", "note": "" },
    { "field": "식비", "amount": 45000, "type": "정액",
      "formula": "27,000원 × 2일 − 조식 포함 1박 × 9,000원", "basis": "…, 제11조 제4항", "note": "" },
    { "field": "숙박비", "amount": 90000, "type": "상한(실비)",
      "formula": "광역시 90,000원 × 1박", "basis": "여비규정 제14조 제2항, 별표 1",
      "note": "영수증 금액으로 실비 정산. 부득이한 사유가 있으면 117,000원까지 가능 (제11조 제6항)" },
    { "field": "철도운임", "amount": 59800, "type": "실비", "formula": "입력 운임 (일반)", "…": "…" }
  ],
  "summary": { "fixed_total": 105000, "lodging_cap": 90000, "transport_total": 59800, "estimated_max": 254800 },
  "notes": ["출장 중 법인카드로 식사했다면 식비 중복 여부를 담당자가 확인합니다 (실무자 의견 기반 가정)."],
  "verify_request": { "trip_type": "국내출장", "grade": "…", "trip": { "…": "…" }, "items": [ "…" ] }
}
```

`type` 으로 화면 표시를 나누면 됩니다: **정액**(그대로 지급) / **상한(실비)**(영수증 금액, 이 금액까지) / **실비**(입력 운임) / **실비(한도)**(자가용) / **감액**.

## 계산 규칙

| 항목 | 계산 | 근거 |
| --- | --- | --- |
| 일비 | 30,000원 × 출장일수 | 여비규정 제14조①, 별표 1 |
| └ 업무용·렌트 차량 | × 1/2 | 제14조① |
| └ 교육 출장 | 출발일·복귀일 2일 한도 | 제14조① 단서 |
| └ 장기 체류 | 도착 다음날부터 15일 초과분 1할, 30일 초과분 3할 감액 | 제14조④ |
| 식비 | 직원 27,000원 × 출장일수 | 제14조①, 별표 1 |
| └ 조식 포함 숙박 | 1박당 식비 1/3 차감 | 제11조④ |
| └ 주최 측 식사 제공 | 1식당 식비 1/3 감액 | 제15조② |
| 숙박비 | 상한 × 박수 (서울 100,000 / 광역시 90,000 / 기타 80,000원), 실비 정산 | 제14조②, 별표 1 |
| └ 부득이한 초과 | 상한의 30%까지 추가 (안내만, 판단은 담당자) | 제11조⑥ |
| └ 주최 측 숙박 제공 | 전액 감액 | 제15조② |
| └ 임원급 | 실비 (상한 없음) | 별표 1 |
| 교통비 | 입력한 운임 실비 | 제13조①, 별표 1 |
| 자가용 | 운행거리 ÷ 유종별 연비(전비) × 출장일 단가 + 통행료, **같은 구간 철도·버스 운임 한도** | 산식: 실무자 의견 반영(멘토 제공), 한도: 제13조⑥, 별표 1 주2) |
| 근무지 내 출장 | 교통비만: 4시간 이상 30,000원 / 미만 15,000원, 업무용 차량·왕복 8km 미만은 0원 | 제16조① |

## 가정한 것

- **자가용 유류비 산식**은 여비규정에 없어 **실무자 의견(멘토 제공 산식, 2026-11 코칭)**을 반영했습니다. 연비는 휘발유 9 · 경유 7 · LPG 6 · 하이브리드 15 km/L, 전기 3.5 km/kWh 입니다. 운행거리는 사무실(근무지)에서 출장지까지 네이버 길찾기 km 기준이며 집 출발은 인정하지 않습니다. 출장일 단가는 안내받은 사이트 기준으로 입력받고, 입력하지 않으면 가정값(휘발유 1,700원/L, 전기 350원/kWh)으로 계산한 뒤 `note`로 알려줍니다.
- 출장시간에 따른 식비 감액(제14조① "출장시간을 고려하여 정액 또는 감액")은 구체 기준이 원문에 없어 계산하지 않았습니다.
