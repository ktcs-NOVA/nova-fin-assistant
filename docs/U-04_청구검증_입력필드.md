# 청구 검증 입력 폼 필드 목록 (U-04)

> 작성: 노은비 · 2026-11-03
> 받는 사람: 프론트엔드 (청구 검증 입력 폼)
> 관련: `docs/API.md` 3-2, `backend/precheck/README.md`, `docs/U-04_검증규칙표.md`

`POST /api/verify` 의 **API.md 3-2 형식은 그대로**입니다. 아래 칸들은 전부 **선택**이라
보내지 않으면 해당 규칙만 건너뛰거나 "담당자 확인 필요"로 안내합니다. 프론트가 단계적으로 늘려도 됩니다.

---

## 0. 먼저 넣으면 좋은 최소 세트 (출장 시연용)

출장·여비 시나리오를 시연하려면 이 칸들이면 충분합니다.

| 화면 칸 | JSON | 없으면 |
|---|---|---|
| 청구 유형 | `trip_type` | 국내출장으로 처리 |
| 직급 | `grade` | 직원 3급 이하로 처리 |
| 출장 시작일 / 종료일 | `trip.start_date`, `trip.end_date` | 일비·식비를 1일로 계산 |
| 출장지 지역 | `trip.region` | 숙박비 상한을 판단 못 함 → 담당자 확인 |
| 교통수단 | `trip.vehicle` | 업무용 차량·자가용 규칙 건너뜀 |
| 항목명 / 금액 | `items[].field`, `items[].amount` | (필수) |
| 숙박: 박수 / 조식 포함 | `items[].nights`, `items[].breakfast_included` | 1박, 조식 미포함으로 처리 |

## 1. 청구 기본 정보 (화면 맨 위, 1번만 입력)

| 화면 칸 | 입력 방식 | JSON | 값 | 필수 |
|---|---|---|---|---|
| 청구 유형 | 드롭다운 | `trip_type` | `국내출장` / `근무지 내 출장` / `법인카드` / `업무추진비` | ✔ |
| 직급 | 드롭다운 | `grade` | `직원 3급 이하` / `직원 1·2급` / `임원/본부장` / `감사` / `사장` | ✔ |
| 제출일 | 자동 (오늘 날짜) | `settlement_date` | `YYYY-MM-DD` | |

## 2. 출장 정보 (청구 유형이 출장일 때만 표시)

| 화면 칸 | 입력 방식 | JSON | 값 | 쓰이는 규칙 |
|---|---|---|---|---|
| 출장 시작일 | 날짜 | `trip.start_date` | `YYYY-MM-DD` | 일비·식비 일수, 출장 중 카드 식사 |
| 출장 종료일 | 날짜 | `trip.end_date` | `YYYY-MM-DD` | 정산 기한 15일 |
| 출장지 지역 | 드롭다운 | `trip.region` | `서울` / `광역시` / `기타` (도시명 `부산`, `세종`, `제주` 등도 가능) | 숙박비 상한 |
| 교통수단 | 드롭다운 | `trip.vehicle` | `대중교통` / `업무용차량` / `렌트차량` / `자가용` | 일비 1/2, 업무용 차량 교통비, 자가용 승인 |
| 자가용 사전승인 받음 | 체크박스 (자가용일 때만) | `trip.private_car_approved` | `true` / `false` | 자가용 승인 |
| 출장시간 | 숫자 (근무지 내 출장만) | `trip.hours` | 시간 | 근무지 내 출장 정액 |
| 왕복 거리 | 숫자 (근무지 내 출장만) | `trip.round_trip_km` | km | 8km 미만 미지급 |

## 3. 청구 항목 (행 추가 방식)

### 3-1. 모든 항목 공통

| 화면 칸 | 입력 방식 | JSON | 필수 |
|---|---|---|---|
| 항목명 | 드롭다운 + 직접 입력 | `field` | ✔ |
| 금액 | 숫자 | `amount` | ✔ |
| 사용일 | 날짜 | `date` | |
| 메모 | 텍스트 | `note` | |

항목명 드롭다운 추천값: `교통비` `철도운임` `항공운임` `숙박비` `식비` `일비` `통행료·주차비` `회의 식대` `업무추진비` `부서운영비` `경조금` `화환` `기타`
→ 항목명으로 규칙 종류를 자동 분류합니다. 메모에 "조식", "특실", "동승", "사유서"가 있어도 인식합니다.

### 3-2. 항목명에 따라 추가로 보이는 칸

| 항목 | 화면 칸 | 입력 방식 | JSON | 쓰이는 규칙 |
|---|---|---|---|---|
| 숙박비 | 박수 | 숫자 | `nights` | 숙박비 상한 (박수 합계) |
| 숙박비 | 조식 포함 | 체크박스 | `breakfast_included` | 식비 1/3 차감 |
| 숙박비·교통비 | 영수증 첨부 | 체크박스 (또는 파일 첨부 여부로 자동) | `receipt` | 증빙 누락 |
| 철도·항공 | 좌석 등급 | 드롭다운 `일반`/`특실`/`이코노미`/`비즈니스` | `seat_class` | 직급별 좌석 |
| 교통비 | 동승자 교통비 | 체크박스 | `passenger` | 동승자 미지급 |
| 교통비(자가용) | 같은 구간 철도·버스 운임 | 숫자 | `public_fare` | 자가용 한도 |
| 법인카드로 결제한 항목 | 결제수단 | 드롭다운 `법인카드`/`개인카드`/`현금` | `payment` | 개인카드 청구, 업무추진비 카드 원칙 |
| 법인카드로 결제한 항목 | 사용 시각 | `HH:MM` | `time` | 심야(23~06시) 사용 |
| 법인카드로 결제한 항목 | 가맹점명 / 업종 | 텍스트 | `merchant`, `merchant_type` | 제한업종, 분할결제 |
| 법인카드로 결제한 항목 | 사유서 첨부 | 체크박스 | `reason_doc` | 심야·휴일·기타주점 사유서 |
| 업무추진비 | 사전결재 받음 | 체크박스 | `pre_approved` | 50만원 이상 사전결재 |
| 업무추진비 | 일상감사 받음 | 체크박스 | `daily_audit` | 100만원 이상 |
| 업무추진비 | 참석자 (상대방 소속·직책·성명) | 텍스트 목록 | `attendees` | 업무관련성 입증 |

## 4. 영수증 화면(U-06) → 청구 항목 연결

`feature/receipt-page` 의 "지출 건 초안"을 **이름 바꾸지 않고 그대로** `items[]` 에 넣어도 됩니다.
엔진이 아래처럼 알아서 바꿔 읽습니다.

| 영수증 초안 | U-04 엔진이 읽는 이름 |
|---|---|
| `purpose` (용도) | `field` (항목명) |
| `business_type` (업종) | `merchant_type` |
| `total_amount` | `amount` |
| `merchant`, `date`, `time`, `amount` | 그대로 |

영수증으로 들어온 항목은 `payment: "법인카드"` 만 같이 넣어주면 심야·제한업종 규칙까지 바로 검사됩니다.

## 5. 응답

API.md 3-2와 같고, 항목마다 `rule_id` 가 하나 더 붙습니다. 결과 카드는 무시해도 되고,
관리자 화면(M-01)에서 "어떤 규칙에 걸렸는지" 필터나 통계를 만들 때 쓸 수 있습니다.

## 6. 요청 예시 (출장 시연 시나리오)

```json
{
  "trip_type": "국내출장",
  "grade": "직원 3급 이하",
  "settlement_date": "2026-11-03",
  "trip": { "start_date": "2026-10-20", "end_date": "2026-10-21", "region": "부산", "vehicle": "대중교통" },
  "items": [
    { "field": "철도운임", "amount": 59800, "date": "2026-10-20", "seat_class": "특실" },
    { "field": "숙박비", "amount": 98000, "date": "2026-10-20", "nights": 1, "breakfast_included": true },
    { "field": "식비", "amount": 54000 },
    { "field": "일비", "amount": 60000 },
    { "field": "저녁 식대", "amount": 32000, "date": "2026-10-20", "payment": "법인카드", "time": "20:10" }
  ]
}
```

→ 철도 특실 **보완 필요**, 숙박비 상한 초과(30% 이내) **담당자 확인 필요**, 조식 포함 식비 **보완 필요**, 출장 중 법인카드 식사 중복 **담당자 확인 필요**, 일비 **규정상 확인 가능**
