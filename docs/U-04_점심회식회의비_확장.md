## 적재 결과 (2026-11-12, 엔진 판정 기준)

17건 중 10건은 기대 판정과 같고 7건은 다릅니다. 다른 건은 전부 "엔진에 해당 규칙이 없어 규정상 확인 가능으로 나온" 경우입니다.

| 케이스 | 기대 | 엔진 | 이유 |
|---|---|---|---|
| ME-001 · 013 · 016 · 017 | 담당자 확인 필요 | 규정상 확인 가능 | 1인당 한도·계정 분류 미확정 (UNK). 자동 판정 금지 자료 |
| ME-008 | 보완 필요 | 규정상 확인 가능 | 영수증 없음(ACC-01)을 업무추진비 항목에서 안 봄 |
| ME-009 | 담당자 확인 필요 | 규정상 확인 가능 | 분할결제지만 사전결재 있음 → 통과 |
| ME-011 | 보완 필요 | 규정상 확인 가능 | 선결제 사후 서식(BIZ-09) 규칙 없음 |

엔진에 넣을지 말지는 팀 결정 사항입니다. 넣는다면 후보는 두 가지뿐입니다.
1. 업무추진비·조직관리비 항목도 `receipt: false` 면 보완 필요 (회계규정 제30조). 관리자 문서 근거라 직원 Q&A 와는 분리.
2. "예산항목 미확정 + 식사·다과" 항목은 담당자 확인 필요로 넘김 (UNK 정책). 규정 근거가 아니라 운영 정책이므로 메시지에 그렇게 적어야 함.

## 자료의 유의사항 (그대로 지킴)

- 1인당 식대·회식·다과 한도는 공개 자료에서 확인되지 않음 → NULL 유지, 초과 자동 판정 금지.
- 50만·100만 원은 1인당 한도가 아니라 **업무추진비로 분류된 건의 건당 절차 기준**.
- 심야·휴일·업종만으로 위반을 확정하지 않음 → 사유서가 있으면 담당자 확인으로.
- 규정 근거는 대부분 B등급(팀 조문 발췌, ALIO 원문 미대조). 원문 확보 전 "최종 조항 확정" 표현 금지.
