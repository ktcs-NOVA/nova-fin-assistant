# U-04 지출 사전검증 — 검증 규칙표

> 작성: 노은비 (직원 정산 흐름 / 기획) · 2026-11-02
> 대상 기관: 한국해양진흥공사 (ALIO 공개 원문, 2026-10-27 확보본)
> 코드: `backend/precheck/` · 기준값: `backend/precheck/rules.py`

제출 전에 청구 내역을 규정과 대조해 **규정상 확인 가능 / 보완 필요 / 담당자 확인 필요** 세 가지로 판정합니다.
AI는 사전검증까지만 하고, **최종 승인·반려는 담당자가 합니다** (3주차 실무자 인터뷰 반영).

## 판정 기준

| 판정 | 언제 | 예 |
|---|---|---|
| 보완 필요 | 규정에 숫자·조건이 명확하고 그걸 어김 | 숙박비 상한 + 30% 초과, 조식 포함인데 식비 전액 |
| 담당자 확인 필요 | 규정상 예외가 가능해서 사람이 판단해야 함, 또는 판단할 정보가 부족 | 자가용 승인 여부, 상한 30% 이내 초과, 정산 기한 경과 |
| 규정상 확인 가능 | 걸린 규칙 없음 | |

## 1. 국내여비 기준값 (여비규정 별표 1, 직원)

| 항목 | 직원 1·2급 | 직원 3급 이하 | 비고 |
|---|---|---|---|
| 일비 | 30,000원/일 | 30,000원/일 | 업무용·렌트 차량 이용 시 1/2 (제14조①) |
| 식비 | 27,000원/일 | 27,000원/일 | 조식 포함 숙박 시 1/3 차감 (제11조④) |
| 숙박비 상한 | 서울 100,000 / 광역시 90,000 / 기타 80,000원 | 같음 | 실비, 부득이 시 30% 추가 (제11조⑥) |
| 철도 | 특실 | 일반실 | 3급 부서장은 2급 기준 적용 가능 (주3) |
| 항공 | 이코노미 | 이코노미 | |
| 자동차 | 실비 | 실비 | 자가용은 철도·버스 운임 이내 (주2) |

- 광역시에는 세종(특별자치시)·통합특별시 포함, 제주·강원·전북(특별자치도)은 "기타" (주4)
- 임원급(사장·감사·본부장)은 숙박비 실비. 감사·임원 식비는 원문 표 셀 병합 때문에 해석이 애매해 **원문 확인 필요**
