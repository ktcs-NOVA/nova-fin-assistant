### 문서를 추가할 때

- 파일 이름은 `규정명(개정일).확장자` 로 맞춰 주세요. 괄호 앞부분이 **규정명**으로 저장되어 답변의 출처에 그대로 표시됩니다.
- 가능하면 한글에서 **HWPX** 로 저장해서 넣어 주세요. HWP 는 표(별표)의 행·열 구조가 사라집니다.
- 같은 규정의 HWP 와 HWPX 를 함께 두지 마세요. 적재할 때마다 서로를 덮어씁니다.
- 파서를 고친 뒤에는 파일 내용이 같아도 `uv run python -m scripts.ingest --force` 로 다시 적재해야 반영됩니다.
- 지원 형식: `.hwp` `.hwpx` `.txt` `.md`
- 관리자 전용 문서(회계규정 등)는 `--audience admin` 으로 적재합니다.
