| 파일 | 최종 개정 |
|---|---|

| 법인카드 관리 및 사용 지침(2025년도 9월 4일 개정).hwpx | 2025.9.4 |
| 업무추진비 및 조직관리비 집행 지침(2025년도 1월 개정).hwpx | 2025.1.6 |
| 위임전결규정(2024년도 9월 개정).hwpx | 2024.9.10 |
| 위임전결규정 시행세칙(2026년도 6월 22일 개정).hwpx | 2026.6.22 |

관리자 전용 문서 (`--audience admin` 으로 적재). 회계·예산·통제·자금 흐름을 구현할 때 참고하는 규정으로, 직원 Q&A 에는 나오지 않습니다.
ALIO 에 HWP 로만 공개되어 있어 HWP 그대로 넣었습니다 (표는 칸 단위로 풀립니다).


### 문서를 추가할 때

- 파일 이름은 `규정명(개정일).확장자` 로 맞춰 주세요. 괄호 앞부분이 **규정명**으로 저장되어 답변의 출처에 그대로 표시됩니다.
- 가능하면 한글에서 **HWPX** 로 저장해서 넣어 주세요. HWP 는 표(별표)의 행·열 구조가 사라집니다.
- 같은 규정의 HWP 와 HWPX 를 함께 두지 마세요. 적재할 때마다 서로를 덮어씁니다.
- 파서를 고친 뒤에는 파일 내용이 같아도 `uv run python -m scripts.ingest --force` 로 다시 적재해야 반영됩니다.
- 지원 형식: `.hwp` `.hwpx` `.txt` `.md`
- 관리자 전용 문서(회계규정 등)는 `--audience admin` 으로 적재합니다.
